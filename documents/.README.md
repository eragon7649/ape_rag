# Documents Directory

Đặt các tệp biên bản cuộc họp vào thư mục này để xử lý.

## Định dạng hỗ trợ

- **PDF**: Biên bản scan, tài liệu điện tử
- **JPG/PNG**: Hình ảnh biên bản viết tay, ảnh chụp màn hình
- **DOCX**: Tài liệu Word

## Ví dụ tên tệp

- `meeting_123_scan.pdf`
- `meeting_124_handwritten.jpg`
- `meeting_125_notes.docx`

## Lưu ý

- Hệ thống sẽ tự động xử lý tất cả tệp trong thư mục này
- Bỏ qua các tệp ẩn (bắt đầu bằng dấu chấm)
- Kết quả sẽ được lưu trong thư mục `output/`
